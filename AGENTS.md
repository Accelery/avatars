# AGENTS.md

## Repo overview

Static site in `public/` plus a Cloudflare Worker in `worker/` that generates PNG avatars. The two parts deploy separately and have no shared tooling.

## Directory layout

```
public/                     # Landing page (genavatar.me): HTML, CSS, theme.js
  index.html
  privacy/index.html
  styles.css
  theme.js                  # Light/dark theme toggle, no build step
worker/                     # Avatar API (api.genavatar.me): TypeScript, workerd
  src/
    index.ts                # Fetch handler, caching, analytics
    _lib/
      index.ts              # createFace() and combine() using @cf-wasm/photon
      blocked.ts            # Scanner path blocklist
      _img/                 # PNG assets for eyes/, nose/, mouth/
  wrangler.jsonc            # Custom domain, Analytics Engine binding, Data rule
  worker-configuration.d.ts # Generated by `pnpm run cf-typegen`
  .wrangler/                # Local dev state, ignored
.github/workflows/
  worker-deploy.yml
.nvmrc                      # Node 26 LTS
```

## Working in `worker/`

Package manager: pnpm. All worker commands run from `worker/`. There is no `package-lock.json`.

```bash
pnpm install
pnpm run dev
pnpm run typecheck
pnpm run deploy
```

- Asset loading: PNGs are imported as `ArrayBuffer` through Wrangler's Data rule in `wrangler.jsonc`. There is no filesystem access at runtime. Do not switch to `fs` or path-based loading.
- Image library: `@cf-wasm/photon` workerd build. Do not use `sharp`.
- pnpm build scripts: `esbuild` and `workerd` are in `pnpm.onlyBuiltDependencies`. Add any new dependency with a postinstall script there too.

## TypeScript config

`strict: true`. Worker globals come from the generated types. Do not add `@types/node`. Node 26 LTS is pinned by `.nvmrc` and `worker/package.json`.

## Analytics

Each avatar request writes one data point to Analytics Engine (`ANALYTICS_ENGINE`, dataset `analytics_avatars`) unless `?notrack=true` is present. Blocked paths and unsupported methods are not tracked.

Fields written:

- `indexes[0]`: referring hostname, or `"direct"` if absent
- `blobs[0]`: route type (`"named"` or `"random"`)
- `blobs[1]`: referring hostname, or `""` if absent
- `blobs[2]`: referring origin + pathname (query string stripped), or `""` if absent
- `blobs[3]`: decoded path ID (max 36 code points), or `""` for random requests
- `blobs[4]`: canonical face key (`c<color>-e<eyes>-n<nose>-m<mouth>`)
- `blobs[5]`: in-worker cache status (`"HIT"` or `"MISS"`)
- `blobs[6]`: Cloudflare edge colo (`request.cf?.colo`)
- `doubles[0]`: `1` (request count)
- `doubles[1]`: handler duration in milliseconds
- `doubles[2]`: response byte length
- `doubles[3]`: `1` on cache hit, `0` on cache miss
- `doubles[4]`: requested output size in pixels

## Caching

Avatar URLs accept `?size=` from 16 to 400. The default is 400, and invalid values fall back to 400.

Rendered PNGs are cached in `caches.default` under `<origin>/__cache/v2/<face.key>-<size>.png`. The cache is local to each Cloudflare edge location. Requests still execute the Worker so analytics can be recorded, while cache hits skip WASM composition.

## CI / deployment

- `worker-deploy.yml` deploys the worker on push to `main` when `worker/**` changes. It uses the `CLOUDFLARE_API_TOKEN` secret.
- Cloudflare Pages deploys `public/` from this repository on push to `main`. No GitHub Actions workflow is involved.

CI runs a TypeScript check before deploying. There is no test or lint step.

## Key dependency

The hashing logic (`hashWithSalt`, `pickIndex`) in `worker/src/_lib/index.ts` uses domain-salted 32-bit FNV-1a with a Murmur3 finalizer. Color, eyes, nose, and mouth are selected independently across 5,184 combinations. Changing this logic changes the mapping for existing IDs, so treat it as a breaking change.

## Writing style

When writing copy for this project (privacy page, landing page, README, etc.):

- No em dashes. Use a regular hyphen or rewrite the sentence.
- No filler phrases like "of any kind", "it is worth noting", "this ensures that".
- No AI list padding. If something can be said in one sentence, do not make it a bullet list.
- Keep sentences short and direct.
