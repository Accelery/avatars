A Gravatar alternative without an account

Deterministic avatars from any ID, with no signup and no API key.

Why use genavatar instead of Gravatar?

Gravatar works well when users already have a Gravatar account. genavatar is for the default avatar case: a user has no uploaded image, and you need a stable face from an ID you already have.

No account or email hash is involved, and you don't upload an image. Put a username, email, UUID, or any other string in the URL.

How they compare

Gravatar genavatar.me
Account Required for a custom avatar None
Identifier Email address hash Any string in the path
Custom image Uploaded by the user Generated from the ID

Size parameter s size, 16 to 400

Switch the image URL

Replace the Gravatar URL with a genavatar URL. Use the same user identifier you already store.

<!-- Before: email hash URL -->
<img src="https://gravatar.com/avatar/HASH?s=96" alt="" width="48" height="48">

<!-- After: username, email, or UUID -->
<img
  src="https://api.genavatar.me/user@example.com?size=96"
  alt=""
  width="48"
  height="48">

Migration notes

  • Use a stable identifier. A username or UUID is usually better than an email address because users can change email.
  • The same ID always maps to the same face, so profile images stay consistent.
  • Request the size you render. Use ?size=96 for a 48px avatar at 2x.
  • Add ?notrack=true if you don't want usage analytics.

FAQ

Is genavatar a drop-in Gravatar replacement?

Not exactly. Gravatar uses email hashes in its URL format. genavatar uses the path as the ID, so you replace the URL and choose the same identifier you already use for the user.

Does genavatar require an email address?

No. Any string works, including usernames, UUIDs, email addresses, Unicode, and emoji.

Are the avatars unique?

There are 5,184 combinations of color, eyes, nose, and mouth. Different IDs can share a face, but the same ID always gets the same one.
