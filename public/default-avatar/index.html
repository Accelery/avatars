Default avatar URL for any user

A stable fallback when a user has no image.

Add a default avatar in HTML

Use the user ID as the path. Request the size you render.

<img
  src="https://api.genavatar.me/user@example.com?size=96"
  alt=""
  width="48"
  height="48"
  loading="lazy">

The image is a 96px square, displayed at 48px. That gives a sharp result on high-density screens.

Use it only as a fallback

Show the uploaded avatar when the user has one. Use genavatar when they don't.

const src = user.avatarUrl
  || `https://api.genavatar.me/${encodeURIComponent(user.id)}?size=96`;

This keeps the profile stable without storing generated images.

Why use a deterministic default?

The same user keeps the same face across sessions and devices. You don't store generated images, and there's no account or API key. Request any size from 16 to 400 pixels.

Choose a stable ID

Prefer a username or UUID over an email address. Email addresses can change, and a change produces a different face.

IDs are case-sensitive and can include Unicode and emoji.

FAQ

What should I use as the avatar ID?

Use a stable identifier such as a username or UUID. Email addresses work too, but users can change them.

What happens when a user uploads an avatar?

Use the uploaded image when one exists. Use genavatar only as the fallback when the user has no image.

Can I request a specific size?

Yes. Add ?size= from 16 to 400. Use twice the rendered size for high-density screens.
