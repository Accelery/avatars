Avatar API integration examples

Copy-paste fallbacks for HTML, React, and Next.js.

HTML

Use the user ID as the path and request twice the rendered size.

<img
  src="https://api.genavatar.me/user@example.com?size=96"
  alt=""
  width="48"
  height="48"
  loading="lazy">

React

This component uses a stable ID and requests a 2x image for high-density screens.

function Avatar({ id, size = 48 }) {
  const px = Math.min(size * 2, 400);
  const src = `https://api.genavatar.me/${encodeURIComponent(id)}?size=${px}`;

  return (
    <img
      src={src}
      alt=""
      width={size}
      height={size}
      loading="lazy"
    />
  );
}

Use it as <Avatar id={user.id} />. Keep the ID stable across sessions.

Next.js

Allow the API host in next.config.ts, then use next/image.

const nextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: "https",
        hostname: "api.genavatar.me",
      },
    ],
  },
};

export default nextConfig;
import Image from "next/image";

function Avatar({ id, size = 48 }) {
  const px = Math.min(size * 2, 400);

  return (
    <Image
      src={`https://api.genavatar.me/${encodeURIComponent(id)}?size=${px}`}
      alt=""
      width={size}
      height={size}
    />
  );
}

The same pattern works in the App Router and Pages Router.

Sizing

Use twice the CSS size for a 2x display. The API supports 16 to 400 pixels, so cap larger avatars at 400.

Display size Requested size
24px ?size=48
48px ?size=96
96px ?size=192
200px ?size=400

Read the reference for caching, CORS, and response headers.
