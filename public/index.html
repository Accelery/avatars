The API is a URL

Anything after the slash becomes the seed. Skip the path for a random face each request. Works with Unicode and emoji.

Built for comment threads, chat defaults, admin user lists, and prototypes that need real-looking faces without storage.

# same ID → same face https://api.genavatar.me/user@acme.com
# no path → new face every time https://api.genavatar.me/
