Random avatar generator API

One URL, a new face on every request.

Get a random avatar

Request the API root with no path. Each request creates a new random face.

  src="https://api.genavatar.me/?size=192"

Open a random avatar

How it works

The Worker generates a UUID, maps it to a face, and returns a PNG. The face comes from the same color, eyes, nose, and mouth parts used for named avatars.

Random responses use Cache-Control: no-store, so the browser does not keep the image. The Worker may still cache the generated face internally by face and size.

Choose a size

Add ?size= from 16 to 400. The default is 400.

https://api.genavatar.me/?size=64
https://api.genavatar.me/?size=192
https://api.genavatar.me/?size=400

When to use random avatars

Use them for mock data and demos, or any layout test where a fresh face matters more than consistency.

Need the same face every time?

Use a named ID instead. The same string always maps to the same face.

https://api.genavatar.me/user@example.com?size=192
